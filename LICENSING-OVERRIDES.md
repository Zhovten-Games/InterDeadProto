# InterDeadProto Licensing Overrides

These overrides apply only to original material owned by the repository rights
holder. They do not replace or weaken third-party upstream licenses, notices,
or other mandatory terms.

## Game audiovisual content

Original game audiovisual content under the following paths is not licensed
under the default `CC-BY-SA-4.0` or `MIT` grants. No license is granted; all
rights are reserved:

- `proto-dev/assets/audio/**`
- `proto-dev/assets/images/**`

Branding and visual identity remain all rights reserved under the default
licensing map independently of this override.

## Narrative and localization content

Original narrative, character, dialogue, lore, and localized game-copy content
under the following paths is not licensed under the default
`CC-BY-SA-4.0` grant. No license is granted; all rights are reserved:

- `proto-dev/src/spirit-contacts/configuration/**`
- `proto-dev/src/localization/locales/**`

Where a file in these paths also contains reusable executable code, the code
structure remains `MIT` unless a more specific notice applies; this override is
limited to the expressive game content embedded in that file.

## Third-party runtime material

No project-specific license is asserted for third-party runtime libraries,
models, or their derived files, including material under:

- `proto-dev/assets/libs/**`
- `proto-dev/assets/models/**`

Those materials retain their original upstream licenses and notices according
to the shared repository licensing policy.
